# First-API-testing-project

API Testing for fake data created by MockAPI (Users data)
✅ Scope of the project:
* GET all users.
* GET one user.
* Create new users.
* Updating users (PUT & Patch).
* Delete user.
* Check on response (time, size, status or value).
* Check on Content-Type header.
* Check on expected data to actual data.

✅Used Technology: Postman.
